# MacroFlow application

Run all npm commands from this directory. See the [build guide](../docs/BUILD.md) for setup, verification, and Android packaging, or the [project README](../README.md) for downloads.

| Path                  | Contents                                              |
| --------------------- | ----------------------------------------------------- |
| `src/`                | React views, nutrition logic, storage, and unit tests |
| `public/`             | Bundled images and fonts                              |
| `android/`            | Capacitor Android project                             |
| `scripts/`            | Production browser checks                             |
| `capacitor.config.ts` | Android app identity and bundled web output           |
| `vite.config.ts`      | Web build and unit-test configuration                 |
