# Download MacroFlow for Android

**[Download MacroFlow APK](https://github.com/raclob/Macroflow/raw/refs/heads/downloads/macroflow-debug.apk)**

Open the downloaded APK on an Android phone (Android 6.0+) and allow installation from your browser or file manager if Android asks. Then open MacroFlow and tap **Make it yours**.

This is the first development preview. Source and build instructions are in [pull request #1](https://github.com/raclob/Macroflow/pull/1).
